# Ice Cream Website

A responsive landing page for an ice cream brand.

The project includes a modern layout, adaptive sections, product presentation, customer reviews, contacts, and a clean visual design.

## Tech Stack

- HTML
- SCSS
- CSS
- JavaScript
- Parcel
- PostHTML Include
- Modern Normalize

## Features

- Responsive layout
- Mobile-first approach
- Product sections
- Customer reviews
- Contacts section
- Modal windows
- Smooth visual styling
- Optimized project structure with partials
